Behind the Scenes

How the agent uses this page

Agent test prompt

Use the WebMCP tools on the open Signal Desk page. Search for admin import customer requests, explain the evidence behind the post-import onboarding gap, draft a customer-impact brief, propose product-owned actions, and show the decision log.

Page tools

  • search_signalsRead-only request search
  • cluster_signalsGroups requests into patterns
  • draft_briefUpdates the customer-impact brief
  • explain_evidenceShows supporting requests
  • propose_actionsAdds reviewable product actions
  • set_review_stateUpdates approval state
  • get_audit_trailReads the decision log
  • reset_demoRestores the seeded case

Browser support

WebMCP tools appear in Chrome Canary with WebMCP enabled or another WebMCP-capable browser host. Any browser can still run the operator workflow with Run Triage.
